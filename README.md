# Bank Customer Churn Analysis

## Problem Statement
Customer churn is a critical issue for banks as acquiring new customers is more
expensive than retaining existing ones.  
This project aims to analyze customer data to identify key factors influencing
customer churn and provide insights that can help improve retention strategies.


## 📌 Project Overview
Customer churn is a major challenge in the banking industry.  
This project analyzes bank customer data to identify patterns and factors that contribute to customer churn, and provides insights that can help improve customer retention strategies.

The analysis focuses on understanding customer behavior using exploratory data analysis (EDA) and statistical insights.

## 📊 Dataset
The dataset contains information about bank customers, including:
- Customer demographics
- Account information
- Credit score
- Balance
- Products used
- Active membership status
- Churn status (Exited or Retained)

---

## 🔍 Objectives
- Analyze customer characteristics associated with churn
- Identify key factors influencing customer exit
- Visualize churn trends across different features
- Provide data-driven insights for retention strategies

---

## 📈 Key Insights
- Customers who are inactive members show a significantly higher churn rate
- Customers using only one product are more likely to exit the bank
- Lower tenure customers tend to churn more than long-term customers
- Customer engagement plays a stronger role than account balance alone

## Final Conclusion
The analysis reveals that customer engagement is the strongest indicator of churn.
Inactive members and customers with low product usage are significantly more likely
to leave the bank. Retention strategies should focus on improving engagement,
especially among new and inactive customers.
